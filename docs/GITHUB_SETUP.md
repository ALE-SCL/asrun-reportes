### 2. Conectar con GitHub
Una vez creado el repositorio, ejecutar:

```bash
# Agregar remote (usar la URL que GitHub te proporcione)
git remote add origin https://github.com/ALE-SCL/asrun-report-generator.git

# Verificar
git remote -v

# Subir todo
git push -u origin main
```
